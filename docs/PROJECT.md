# 言练项目说明

## 产品定位

言练是一款本地优先的中文口语表达训练工具。它不是一次性给出长篇评价，而是帮助用户完成一个可重复的训练闭环：

> 说一次 → 看见真实反馈 → 带着一个建议再试一次 → 重新评估

## 当前阶段

- **阶段**：早期可用版本 / 持续验证
- **当前核心体验**：录音、离线转写、实时提示、训练报告、按目标再练一次
- **当前首要问题**：用户完成第一次训练后，持续训练的动力不足
- **当前产品假设**：如果用户能清楚看见“这次比刚才好在哪里”，继续训练的意愿会明显提高

## 产品原则

1. **完整反馈，开放练习**：报告呈现主要问题，可以给出一个练习建议，但不把下一轮锁定在单一问题上。
2. **先让用户看见进步**：反馈必须具体、有原话证据。
3. **行动优先于解释**：每份报告都要导向下一轮 30～90 秒训练。
4. **不做心理判断**：只分析可观察到的表达行为。
5. **区分 ASR 错误与表达问题**：残句、错字不能直接用于能力判断。
6. **本地优先**：语音识别和基础分析尽量保留在本机。
7. **小步迭代**：每轮只解决一个主要体验问题，完成验证后再进入下一轮。

## 核心用户路径

1. 用户开始录制或导入逐字稿。
2. 系统给出实时但不过度打扰的反馈。
3. 用户结束训练并生成报告。
4. 报告呈现亮点与多个改进机会，并给出一个可立即尝试的建议。
5. 用户点击“开始下一轮”，可以参考该建议重新表达。
6. 系统重新分析整段表达，并比较前后两轮的变化。

第 6 步是下一阶段需要补齐的核心能力。

## 成功指标

早期不追求复杂数据面板，优先观察以下行为：

- 完成首轮后，是否点击“开始下一轮”。
- 一次使用中完成的训练轮数。
- 用户是否参考报告建议完成至少两轮。
- 用户第二天是否再次打开应用。
- 用户是否能说清楚自己下一轮想尝试的调整。

## 项目边界

当前阶段暂不优先：

- 排行榜、积分商城和复杂徽章系统。
- 多人社交或公开内容社区。
- 面面俱到的人格、情绪或心理分析。
- 为了功能数量而增加的复杂设置。
