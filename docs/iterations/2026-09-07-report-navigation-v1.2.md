# 报告信息架构与跳转 V1.2

- 日期：2026-09-07
- 状态：已实现，待真实训练验证
- 本轮问题：报告虽然已有分段，但各章节权重相近，只强调“一个问题”会掩盖其他有效观察，长内容也缺少快速跳转能力。

## 本轮假设

如果报告完整展示少量关键改进机会，同时明确一个本轮优先训练项，并提供可跟随滚动的章节目录，用户会更容易理解全貌、确定顺序并开始下一轮。

## 信息架构

1. 本轮概览
2. 表达亮点
3. 改进机会
4. 本轮优先训练
5. 修改示范
6. 立即再练
7. 数据与原文

核心原则调整为：

> 问题可以有多个，训练目标只设一个。

## 已做改动

- 报告生成规则改为列出 2～4 个有原话证据的改进机会。
- 每个改进机会标记为“本轮优先”“后续可练”或“持续观察”。
- 单独解释为什么选择当前优先训练项，以及本轮可以暂时放下什么。
- 报告增加固定章节目录，点击可平滑跳转。
- 滚动报告时，目录自动高亮当前章节。
- 报告章节增加概览、改进机会、修改示范等差异化视觉层级。
- 完整逐字稿移动到“数据与原文”中的折叠区域。
- 复制报告时不再混入目录按钮文字。
- 窄窗口下，纵向目录自动变成可横向滚动的章节导航。

## 保持不变

- 不输出总分。
- 不进行人格或心理判断。
- 所有判断需要原话证据。
- 下一轮仍然只带入一个训练目标。
- 录音、语音识别和实时词库分析逻辑不变。

## 验证重点

1. 用户能否在 10 秒内找到“本轮优先”。
2. 用户是否理解“改进机会有多个，但当前只练一个”。
3. 左侧目录是否比连续滚动更容易定位内容。
4. 报告长度是否仍然可接受。
5. 完整原文折叠后，主体是否更清晰。
