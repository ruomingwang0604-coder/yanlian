# 瑞士风训练报告 V1.4

- 日期：2026-09-07
- 状态：已实现，待持续体验验证
- 参考：`guizang-ppt-skill` 的 Swiss International Style 视觉规范
- 本轮问题：报告和录音首页仍是深色圆角卡片体系，长报告显得零散，首页与报告也缺少统一的视觉语言。

## 设计方向

采用克莱因蓝（IKB）主题，将 PPT 的瑞士风原则转译为桌面长报告，而不是直接照搬幻灯片：

- 灰白纸张背景、近黑正文和单一克莱因蓝强调色。
- 以严格网格、细分隔线和大号章节编号代替层层圆角卡片。
- 综合分使用巨型数字，六维评分使用同色雷达图与水平条。
- 目录采用编号索引结构，当前章节使用整块蓝色标识。
- 表格、评分子项和引用统一使用直角边框。
- 去除报告区域的粉、绿、黄、紫多色体系，以及渐变和装饰性阴影。
- 录音首页同步采用浅色纸张、黑色分隔线、蓝色单一强调和直角控件。
- 报告底部不使用整块蓝色背景，只保留左侧蓝色定位条和蓝色行动按钮。

## 保持不变

- 六维评分算法、权重和前端复算逻辑。
- 九章报告结构与目录跳转。
- 多个改进机会和开放式“建议先试”。
- Markdown 保存、复制全文、完整逐字稿折叠。
- 录音、语音识别和实时反馈功能。

## 验证重点

1. 用户是否更容易把报告看成一份有层级的专业训练文档。
2. 综合分与六维差异是否能在第一屏被快速读懂。
3. 长文本在浅色纸张上的阅读舒适度是否优于深色卡片。
4. 蓝色是否使用克制，没有重新变成“满屏强调”。
5. 窄窗口中的横向目录和评分模块是否仍然可用。
