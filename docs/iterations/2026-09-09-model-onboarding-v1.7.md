# V1.7 首次启动模型准备

日期：2026-09-09

## 用户问题

V1.6 将语音模型直接放入 DMG，虽然离线可用，但安装包约 350 MB，不利于下载、分享和持续更新。

## 本轮目标

把应用本体与语音模型分开：用户首次打开时在应用内完成下载，看到真实进度，下载结果经过校验，失败后可以继续重试。

## 实现范围

- 从 Electron Builder 的 `extraResources` 中移除模型目录。
- 安装版将模型保存到 Electron 用户数据目录下的 `models/`。
- 开发版继续优先使用仓库中的本地模型，方便开发调试。
- 使用固定版本的 Hugging Face 文件地址，ModelScope 作为备用下载源。
- 对 `encoder.int8.onnx`、`decoder.int8.onnx` 和 `tokens.txt` 校验文件大小与 SHA-256。
- 使用 `.part` 临时文件和原子重命名，避免把中断下载误认为完整模型。
- 已校验文件会在失败重试时复用。
- 首次启动界面展示总体进度、当前文件、校验阶段和错误信息。
- 模型就绪后关闭准备界面并进入训练。

## 验收标准

- 新安装包中不存在模型 ONNX 文件。
- 首次启动会出现模型准备界面。
- 下载过程中百分比和已下载容量持续更新。
- 校验失败时不能进入录音，并显示重新下载按钮。
- 三个文件全部校验通过后才能初始化 ASR。
- 已有完整模型时启动不重复下载。

## 验证结果

- 从空目录启动开发版，完整下载 237,202,501 字节（界面约 226.2 MB）。
- 三个模型文件的实际 SHA-256 与清单一致。
- 下载完成后准备界面自动关闭，`initASR()` 初始化成功。
- 安装版在无模型时正确显示准备页，在已有已校验模型时可直接进入训练并初始化 ASR。
- `Yanlian-0.2.0-mac-arm64.dmg` 约 142 MB；上一版 DMG 约 350 MB，体积减少约 59%。
- 安装版 `.app` 中未发现 `.onnx`、`tokens.txt` 或模型压缩包。
