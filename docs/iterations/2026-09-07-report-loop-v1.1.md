# 报告闭环 V1.1

- 日期：2026-09-07
- 状态：已实现，待真实用户验证
- 本轮问题：旧报告信息太多、像一次性批改，用户看完缺少继续训练的动力。

## 本轮假设

如果报告只保留一个明确训练焦点，并让用户能够直接带着该目标开始下一轮，用户更容易持续完成训练。

## 已做改动

- 报告标题调整为“这轮，只练一件事”。
- 固定结构为：本轮一句话、进步信号、值得保留、只改一件事、立即再练、本轮记录。
- 取消总分、全面逐句批改和心理化判断。
- 报告底部增加固定行动区，持续显示下一轮目标。
- “开始下一轮”会关闭报告、重新录音并带入训练焦点。
- 增加报告生成中的明确等待状态。

## 技术验证

- JavaScript 语法检查通过。
- Git diff 格式检查通过。
- 1400×900 窗口报告视觉检查通过。
- 模拟完整流程通过：导入逐字稿 → 生成报告 → 提取目标 → 开始下一轮。
- 测试提取目标：`先结论，后解释`。

## 下一步验证

需要通过实际训练回答：

1. 报告是否仍然太长？
2. 唯一训练目标是否真的可执行？
3. 用户是否愿意连续完成第二轮？
4. 第二轮结束后，用户是否能感知自己的变化？

第四个问题将由“前后两轮对比 V2”解决。
