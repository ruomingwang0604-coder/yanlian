# 独立应用身份与安装包 V1.6

日期：2026-09-09

## 问题

当前产品虽然已经使用“言练”品牌，但 npm 包名、开发安装方式和模型路径仍明显沿用上游项目，普通用户必须接触源码、Node.js 和命令行，无法把它当作一个独立桌面产品使用。

## 本轮目标

建立“言练”自己的桌面应用身份和 macOS 安装包基线，不在这一轮同时引入自动下载模型与复杂首次启动流程。

## 改动

- npm 包名改为 `yanlian-desktop`。
- 增加独立应用 ID：`com.ruoming.yanlian`。
- 增加独立应用图标和 macOS 麦克风权限说明。
- 增加 Electron Builder 配置与 Apple Silicon DMG 构建命令。
- 打包时将本地语音模型放入应用资源目录。
- ASR 在开发环境和安装包环境分别解析正确的模型路径。
- README 把普通用户安装与开发者源码运行拆开，并准确说明在线 AI 的数据边界。
- 增加第三方组件与模型许可证说明。

## 完成标准

- `npm run check` 通过。
- `npm run pack:mac` 可以生成可启动的 `言练.app`。
- 打包后的应用包含独立 bundle ID、图标和麦克风权限描述。
- 打包后的应用能够找到内置语音模型。
- `npm run dist:mac` 可以生成 Apple Silicon DMG。

下一轮实现首次启动自动下载模型、下载进度、失败重试与模型完整性校验，从而减小安装包体积。
